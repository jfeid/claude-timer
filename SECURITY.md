# Security

## Reporting a vulnerability

Please report security problems privately, by email to
info@maxweb.gr (Giannis Feidaros), not in a public issue.

Include what you found, how to reproduce it, and the plugin version
(`.claude-plugin/plugin.json`). You will get an answer within 7 days. A
confirmed problem is fixed in a new version, and the report credits you
unless you ask otherwise.

## Supported versions

Only the latest version on the `main` branch gets fixes.
